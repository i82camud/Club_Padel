# QUICK START - Club Padel

## Para ejecutar en otro PC (Windows PowerShell)

```powershell
# Copiar/clonar la carpeta Club_Padel

# Abrir PowerShell en esa carpeta y ejecutar:

# 1. Crear entorno (solo 1ª vez)
python -m venv .venv

# 2. Activar
.\.venv\Scripts\Activate.ps1

# 3. Instalar (solo 1ª vez)
pip install -r requirements.txt

# 4. Base de datos (solo 1ª vez)
python scripts/reset_db.py
python scripts/seed_test_data.py

# 5. Ejecutar (cada vez)
python main.py
```

---

## Para ejecutar en otro PC (macOS/Linux)

```bash
# cd a la carpeta Club_Padel

# 1. Crear entorno (solo 1ª vez)
python3 -m venv .venv

# 2. Activar
source .venv/bin/activate

# 3. Instalar (solo 1ª vez)
pip install -r requirements.txt

# 4. Base de datos (solo 1ª vez)
python scripts/reset_db.py
python scripts/seed_test_data.py

# 5. Ejecutar (cada vez)
python main.py
```
